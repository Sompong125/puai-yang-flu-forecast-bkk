## โจทย์ (R1)
พยากรณ์จำนวนผู้ป่วยไข้หวัดใหญ่รายเขตของ กทม. ล่วงหน้า 1 สัปดาห์ เพื่อให้สำนักอนามัยตัดสินใจส่งทีมคัดกรองและจัดสรรยาต้านไวรัสไปยังเขตที่คาดว่าผู้ป่วยจะเพิ่มขึ้น
(1 แถว = 1 เขต × 1 สัปดาห์ · ทำนายทุกวันจันทร์ ใช้ข้อมูลถึงวันอาทิตย์ก่อนหน้า)

## สรุปผลลัพธ์ (ทดสอบบน test 16 สัปดาห์: 6 ก.ค.–19 ต.ค. 2026)
| วิธี | MAE (ราย/เขต/สัปดาห์) | ช่วงความเชื่อมั่น 95% | ทำนายต่ำกว่าจริง | Top-10 hit |
|---|---|---|---|---|
| Baseline (ค่าสัปดาห์ก่อน) | 16.06 | 13.75–18.44 | 54.9% | 0.74 |
| Ridge | 14.90 | 12.91–17.04 | 53.8% | 0.76 |
| Random Forest | 17.07 | 14.34–20.10 | 55.4% | 0.71 |

- **สรุปไม่ได้ว่าโมเดลชนะ baseline** ผลต่างของ Ridge = −1.16 [−3.28, +0.77] ซึ่งคร่อม 0
- **จุดที่พลาด:** ช่วงผู้ป่วยกำลังเพิ่ม baseline ทำนายต่ำกว่าจริง 69% ของเขต-สัปดาห์ เทียบกับ 24% ช่วงกำลังลด (สัปดาห์ 10 และ 17 ส.ค. 2026 สูงถึง 90% และ 94%) ทั้ง Ridge และ Random Forest พลาดในทำนองเดียวกัน
- **ข้อเสนอ:** ใช้ค่าสัปดาห์ก่อนเป็นฐานวางแผน และเผื่อทีม/ยาสำรองเมื่อยอดรวม กทม. เพิ่มขึ้น (ข้อเสนอนี้ยังไม่ได้ทดสอบเป็นกฎ)
- **ข้อจำกัด:** test เป็นฤดูเดียว ราว 16 จุดเวลา · ข้อมูลเป็นจำนวนไม่ใช่อัตราต่อประชากร · ตัดสัปดาห์ท้ายปี 2025 ที่รายงานไม่ครบ · เราเห็นยอดรวมช่วง test ก่อนล็อกวิธีแบ่ง (เปิดเผยใน R7) · ข้อมูลไม่ระบุ license

## โครงสร้าง repo
```
Puai-Yang-Flu-Forecast-BKK/
├── README.md              # ไฟล์นี้
├── data/
│   ├── raw/               # ไฟล์ดิบ (ไม่อยู่ใน repo ดู raw/README.md)
│   ├── processed/         # ตารางเขต × สัปดาห์ที่ทำความสะอาดแล้ว
│   └── README.md          # คำอธิบายชุดข้อมูล
├── src/
│   ├── main.py            # รันทั้งโครงงาน
│   ├── preprocess.py      # ทำความสะอาดข้อมูล (R2)
│   ├── analysis.py        # EDA + โมเดล + จุดที่พลาด (R3–R5)
│   ├── utils.py           # ฟอนต์ไทย/สไตล์กราฟ
│   └── CPE312_Capstone_Super_Chicken_v5.ipynb   # notebook ฉบับเต็ม R1–R7 (Colab)
├── results/
│   ├── figures/           # กราฟ
│   └── output/            # ตารางผลลัพธ์ + run_log.txt
├── requirements.txt
└── .gitignore
```

## วิธีรัน
```bash
pip install -r requirements.txt

# แบบที่ 1: ไม่ต้องมีไฟล์ดิบ ใช้ตารางที่ทำความสะอาดแล้วใน data/processed/
python src/main.py --skip-preprocess

# แบบที่ 2: เริ่มจากไฟล์ดิบ (วาง 3 ไฟล์ใน data/raw/ ตาม data/raw/README.md)
python src/main.py
```
ผลลัพธ์: กราฟใน `results/figures/` · ตารางใน `results/output/` · log เต็มใน `results/output/run_log.txt`
สคริปต์ใน `src/` ตัดมาจาก notebook โดยไม่เปลี่ยนตรรกะ ถ้าต้องการดูทีละขั้นพร้อมคำอธิบาย ให้เปิด notebook ใน Google Colab
