ไฟล์ดิบไม่ได้อยู่ใน repo เพราะ
1. ขนาดใหญ่ (3 ไฟล์ รวมราว 195 MB)
2. เป็นข้อมูลผู้ป่วยระดับรายแถว (อายุ เพศ อาชีพ แขวง/เขต สถานที่รักษา แม้ไม่มีชื่อหรือรหัสผู้ป่วย)
3. หน้าชุดข้อมูลระบุ "License not specified" จึงไม่แจกจ่ายซ้ำ
